## cross-image invariants (17 imgs)
- TFs seen: 30m (t1 ctx, T2, T3, T4), 4m (t1 exec), 5m (T5, T6, T7) — always read from toolbar dropdown
- boxes hug candle BODIES; wick extremes are NEVER inside boxes — they get separate objects (red lines / blue dash / circles / "SWING (EXTREME)" text)
- entry = interior of block (explicit "ENTRY IN MID OF BLOCK" x2; 1141 inside FVG; 1269.4 mid-OB; 1875 mid-box)
- SL = just beyond box edge (1224 vs 1223.5; 1133.07 vs 1134.7; 1870 vs 1871; 2076 vs 2070), NEVER beyond the wick extreme
- sequence grammar: liquidity line/extreme → sweep → BOS (line or band box) → OB/breaker/mitigation/FVG at origin → retest entry → exit at opposing structure/OB/origin level
- box right edges: mostly hand-dragged a few days right (not infinite); only pure horizontal-line tools (entry/SL/extreme lines) run full-width with axis tags
